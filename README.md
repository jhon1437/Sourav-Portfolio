# Sourav S – Professional Portfolio Website

## Overview

This project is a modern, responsive personal portfolio website designed to showcase the professional profile, skills, certifications, projects, work experience, and contact information of Sourav S.

The portfolio features a dark-themed cybersecurity-inspired design with smooth animations, interactive UI elements, and mobile responsiveness. Although initially styled with cybersecurity aesthetics, the content has been adapted to highlight expertise in Platform Operations, User Support, Community Management, CRM Operations, AI Productivity Tools, and Social Impact Initiatives.
